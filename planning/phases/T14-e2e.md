## Known bugs (fix in this task)

1. **Fixed (2026-10-05): Android launch `listenFailed`.** `AndroidPlatformServices.initialize` requests `BLUETOOTH_SCAN`, `BLUETOOTH_ADVERTISE`, and `BLUETOOTH_CONNECT` before the radio starts. A listen or scan throw is recorded on `advertError` and the shell still opens. The plugin still returns only the short code, so the banner does not include the native exception text.
